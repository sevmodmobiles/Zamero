# Замеро — обмен помещений

Android-приложение, через которое можно обменять одно помещение на другое (квартиру,
комнату, дом, коммерческое помещение) — **быстро, с минимумом действий и с максимальным
шансом найти вариант**.

## Главная идея

На обычной доске объявлений человек сам ищет того, кто хочет именно его квартиру и при этом
продаёт ту, что нужна ему. Такое совпадение бывает редко. Замеро ищет варианты сама,
в том числе **цепочки обменов**:

```
Анна (Марьино)  ──хочет──▶  Борис (Хамовники)
      ▲                              │
      │                            хочет
    хочет                            ▼
      └────────────────────  Вера (Бутово)
```

Ни одна пара тут напрямую не меняется, но втроём все получают то, что хотели.
Доплаты считаются автоматически: каждый платит разницу в стоимости, и в сумме по
цепочке доплаты дают ноль.

## Принципы

**Просто**
- Объявление — две короткие части: «Что у меня есть» и «Что я ищу». Без длинных анкет.
- Доплата задаётся одним ползунком: «готов доплатить до X» ↔ «хочу получить от X».
- Пользователь ничего не ищет сам: приложение показывает готовые варианты и присылает
  уведомление, когда появляется новый.

**Эффективно**
- Ищем не только прямые обмены, но и цепочки до 4 участников.
- Варианты сортируются по тому, насколько они совпадают с пожеланиями: учитываются
  порядок районов и запас по площади. Короткие цепочки идут выше, потому что их реже срывают.
- `bestPlan()` подбирает набор непересекающихся сделок, чтобы одновременно провести
  как можно больше обменов.

## Структура проекта

| Модуль | Что внутри |
|---|---|
| `core/` | Чистый Kotlin без Android: модель (`Listing`, `Property`, `Wish`), правила совпадения (`Fit`), поиск обменов (`MatchingEngine`), тесты. Потом этот код можно перенести на сервер. |
| `app/` | Android-приложение на Jetpack Compose: форма объявления и экран вариантов. Пока работает на демо-данных из `SampleData`. |

Сборка: `./gradlew :core:test :app:assembleDebug` (JDK 17, Android SDK 35).
CI в GitHub Actions на каждый push запускает тесты и собирает debug-APK
(его можно скачать в артефактах сборки).

Чтобы проверить работу на демо-данных: город Москва, квартира, район «Ясенево», 2 комнаты, площадь любая,
стоимость 13 млн; ищу «Хамовники». Должен найтись прямой обмен с Борисом.

## Дорожная карта

1. **MVP (сейчас):** подбор обменов, форма, список вариантов на демо-данных.
2. **Сервер:** хранение объявлений, подбор на бэкенде (по мере роста базы — с индексами
   по городу и району), вход по номеру телефона.
3. **Сделка:** подтверждение участия каждым участником цепочки, общий чат, статусы
   («все согласны» → «просмотры» → «документы»), push-уведомления.
4. **Доверие:** фото и проверка документов на помещение, отзывы.
5. **Расширенные обмены:** разъезд (1 → 2) и съезд (2 → 1), автоматическая оценка
   стоимости по рыночным данным, карта районов вместо ввода текстом.
