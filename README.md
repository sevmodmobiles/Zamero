# Замеро — обмер помещений

Android-приложение для быстрого и точного обмера помещений. Значения можно вводить
тремя способами, в любом сочетании:

| Способ | Как работает |
|---|---|
| **Вручную** | Поле ввода понимает «3.45», «3,45», «345 см», «3450 мм». |
| **Bluetooth-рулетка** | Подключили один раз, дальше просто нажимаете кнопку на рулетке — значение само попадает в нужное поле. |
| **Камера (AR)** | Наводите прицел на начало отрезка, потом на конец: ARCore считает расстояние. Подходит для быстрых замеров, когда нет рулетки. |

У каждого значения сохраняется источник (вручную / рулетка / камера), чтобы было видно,
насколько ему можно доверять.

## Как сделан процесс быстрым

- **Пошаговый обмер.** Приложение само говорит, что мерить дальше: «Стена 1 → Стена 2 → …
  → Высота → Окно 1: ширина…». После каждого замера поле переключается автоматически,
  телефон вибрирует. С рулеткой экран почти не нужно трогать.
- **Эскиз с номерами стен.** Видно, какая стена «Стена 2», и она подсвечивается.
- **Формы-шаблоны.** Прямоугольник и Г-образное помещение (все углы 90°).
- **Проверка замеров.** Если противоположные стены расходятся больше чем на 3 см, приложение
  предупреждает: «Контур не сходится — перемерьте». Небольшое расхождение распределяется
  между стенами, как при обработке геодезического хода.
- **Сразу считает** площадь пола, периметр, площадь стен без окон и дверей, объём.
- **Отчёт одной кнопкой** — «Отправить» делится текстовым отчётом через мессенджер или почту.
- Данные сохраняются на телефоне автоматически.

## Поддерживаемые рулетки

| Протокол | Устройства |
|---|---|
| Leica DISTO (BLE, float32) | DISTO D1, D2, D110, D510 и др. |
| Nordic UART (текст) | рулетки с UART-модулем |
| HM-10 / JDY, сервис FFE0 (текст) | многие недорогие рулетки |

Bosch GLM, Mileseey и другие используют свои закрытые протоколы. Их добавим, когда
будут устройства для проверки. Профиль добавляется в `laser/LaserProfiles.kt`.

## Структура

| Модуль | Что внутри |
|---|---|
| `core/` | Чистый Kotlin: модель (`Project`, `Room`, `Measure`), геометрия и проверка контура (`Geometry`), пошаговый обмер (`MeasureFlow`), разбор данных рулеток (`LaserParsers`), отчёт (`Report`). Покрыт тестами. |
| `app/` | Android, Jetpack Compose: список помещений, экран обмера, подключение рулетки (`laser/`), AR-замер (`ar/`), хранение (`data/`). |

## Сборка APK

Сборка идёт в GitHub Actions на каждый push:

1. запускаются тесты `core`;
2. собирается debug-APK;
3. APK выкладывается в релиз **latest**: *Releases → latest → zamero-N.apk*. Его можно
   скачать прямо на телефон и установить. Каждая новая сборка ставится поверх старой.

Локально: `./gradlew :core:test :app:assembleDebug` (JDK 17, Android SDK 35).
